# STC Enterprise Architecture

**Academic Team Project | Enterprise Architecture**

## Project Overview

An academic enterprise architecture case study examining STC's business and IT architecture using the TOGAF framework.

The project explores how enterprise architecture can support business and technology alignment, improve system integration, and enable digital transformation.

## Project Objectives

- Analyze the organization's business and IT environment.
- Identify architectural challenges and improvement opportunities.
- Apply the TOGAF Architecture Development Method (ADM).
- Examine the alignment between business processes and IT systems.
- Propose architectural improvements to support digital transformation.

## Enterprise Architecture Analysis

### 1. Business Architecture
- Business processes and organizational capabilities
- Business objectives and strategic alignment
- SWOT analysis

### 2. Data Architecture
- Data management considerations
- Information flow and integration requirements

### 3. Application Architecture
- Application integration
- Relationships between enterprise systems

### 4. Technology Architecture
- Technology infrastructure
- Architecture improvement opportunities

## Framework

**TOGAF (The Open Group Architecture Framework)**

The case study applies enterprise architecture concepts and TOGAF ADM to assess the current environment and propose a future-state architecture.
